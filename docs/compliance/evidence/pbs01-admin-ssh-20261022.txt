=== 11. METHOD NOTE: why this gate nearly reported a false gap ===
audit.log uses log_format=ENRICHED, so it is partly BINARY. Three mismatches each produced a
misleading zero:
  (a) grep -c "TYPE=SYSCALL"  -> 0   (raw file uses lowercase type=; uppercase is ausearch output)
  (b) grep -c "key=firewall"  -> 0   (keys are QUOTED in the raw file: key="firewall")
  (c) plain grep without -a on a binary file under-reports silently
Also 'ausearch -k firewall' with no time bound scans all retained logs and exceeds 60s.
Lesson: prove a logging control is dead with a correctly-formed query, never with one empty grep.
